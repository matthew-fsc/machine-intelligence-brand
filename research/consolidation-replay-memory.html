Consolidation, replay, and agent memory architecture

The brain keeps a fast store and a slow one and moves experience between them while you sleep. Agent memory has the same layers, and one operation biology runs automatically that no vector store performs.

abstract

Biological memory is not one store but a division of labour: a fast hippocampal system that binds new episodes, and a slow neocortical system that integrates them over time, with sleep replay ferrying experience between the two. Agent memory has its own layers: the context window, a vector store for retrieval, episodic scratchpads, summarization, and offline distillation from trajectories. The layered structure rhymes. But retrieval is not recall, and nothing in a vector store is reconsolidated on access the way a biological memory is. The central analogy holds at analogy.

01Two stores, one system

The dominant account of human long-term memory is the complementary learning systemsThe theory that the brain uses a fast-learning hippocampus and a slow-learning neocortex together, so new memories can be acquired quickly without overwriting old knowledge. theory of McClelland, McNaughton and O'Reilly 1. The hippocampus learns fast, binding the elements of a single experience into an episode after one exposure. The neocortex learns slowly, extracting statistical structure across many experiences. The split solves a real engineering problem: fast learning that overwrites is unstable, and slow learning alone cannot capture a one-time event. Keep both, and you get rapid acquisition without catastrophic overwriting.

An agent stack has a comparable separation, though it arrived by convenience rather than design. The context window is a fast, high-fidelity, short-lived store: everything in it is available at full resolution, and all of it vanishes when the session ends. The model weights are a slow store: they change only through training and hold structure distilled across the whole corpus. Between them sit external memories, vector databases, files, scratchpads, that persist across sessions without touching the weights. The three-tier arrangement, fast and volatile, slow and stable, plus a persistent external tier, is the practical shape of agent memory today.

02Replay and consolidation

What moves a memory from the fast store to the slow one is consolidationThe process by which a labile new memory becomes stable and integrated into long-term neocortical storage, much of it during sleep., and its signature mechanism is replay. Wilson and McNaughton recorded hippocampal place cells reactivating during sleep in the same sequences they had fired during waking experience 2. During sharp-wave ripplesBrief high-frequency bursts of hippocampal activity, prominent in rest and sleep, during which waking experience is replayed in compressed form., the day's trajectories are replayed in compressed form, and this offline reactivation is thought to train the neocortex gradually, interleaving new episodes with old knowledge so the slow store integrates them without disruption 3.

Machine learning independently discovered the value of replay. Experience replay in deep reinforcement learning stores transitions in a buffer and samples them repeatedly to train the network, breaking correlations and reusing rare experiences; it was central to the first deep agent to reach human-level play across Atari games 4. For language agents, the offline analogue is distillation from trajectories: collect the traces of an agent solving tasks, filter for the successful ones, and fine-tune on them so that behaviour which required a long deliberate rollout becomes available in a single pass. That is consolidation in spirit, slow structure absorbing what fast processing produced.

03Interference and forgetting

Forgetting is not a bug the brain failed to fix; it is the shape of a finite system under interference. Ebbinghaus measured the forgetting curve on himself over a century ago, and its steep early drop followed by a long tail has held up 5. New learning interferes with old, and old with new, which is exactly the pressure complementary learning systems evolved to manage.

Neural networks have their own, harsher version. McCloskey and Cohen named catastrophic interferenceThe tendency of a neural network to abruptly lose previously learned information when trained on new data, because the same weights encode both.: train a network on task B and it can lose task A almost entirely, because the same weights carry both and gradient descent has no reason to protect the old 6. Interleaved replay is one of the standard defences, which is part of why the biological solution and the engineering solution converge on the same move: do not learn new things in isolation, rehearse them alongside the old.

For a language agent, the interference lives at a different layer. The weights are frozen during deployment, so the catastrophic case does not arise per session. Instead the pressure shows up in the context: finite window, so older turns are dropped or summarized, and in retrieval, where a growing store makes the relevant memory harder to surface. The failure mode is not overwriting but crowding and mis-retrieval.

Forgetting is the shape of a finite system under interference, not a defect it failed to fix.

04Agent memory in practice

The working toolkit is small and worth naming precisely. Retrieval-augmented generation fetches passages by similarity and places them in context, the pattern Lewis and colleagues formalised 7. Episodic scratchpads let an agent write notes to itself across steps. Summarization and compaction compress old context into shorter form to fit the window. Offline distillation turns successful trajectories into weight updates. Each of these is a memory operation, and each has a loose biological echo: retrieval as cued recall, scratchpads as working memory held externally, summarization as gist extraction, distillation as consolidation.

The echoes are useful for design intuition. Sleep research suggests that consolidation is selective, that salient and rewarded experiences are preferentially replayed 8. An agent that distills every trajectory equally is ignoring that lesson; one that weights replay toward informative or successful episodes is closer to how the biological system spends its offline budget. The analogy pays off precisely where it suggests a policy you would not otherwise have written down.

where the mapping breaks

Retrieval is not recall, and nothing reconsolidates

A vector store returns the stored item unchanged. You embed a query, find the nearest neighbours, and hand back the passages exactly as they were written. Biological recall does no such thing. Retrieving a memory reactivates it, and reactivation opens a window in which the memory becomes labile and must be restabilised, often in altered form. Nader, Schafe and LeDoux showed that a consolidated fear memory, once recalled, requires new protein synthesis to persist, and can be disrupted or changed during that window 9. This is reconsolidationThe finding that recalling a memory returns it to an unstable state, requiring restorage, during which it can be updated, strengthened, or impaired., and it means a human memory is edited a little every time it is used.

Nothing in the standard agent stack does this. Reading a passage from a vector store leaves it byte-for-byte identical; accessing it a thousand times changes nothing about what is stored. The store is a filing cabinet, not a living trace. That difference is not a detail. Human memory's fallibility and its adaptiveness are the same property: memories drift toward coherence, absorb new context, and update on use. A retrieval system that never reconsolidates is more faithful and less intelligent, holding stale facts perfectly while a person would have quietly revised them.

A second break: consolidation in biology is a physical transfer between distinct anatomical systems with different learning rates. In an agent, the "transfer" from context to weights only happens if an engineer runs a training job. Absent that, the fast store never becomes the slow store; the session ends and the episode is gone unless it was written to the external tier. The layered diagram looks the same, but one version runs the pumps automatically and the other waits for a human to start them.

06Implications for prompt and agent design

  • Replay selectively, not uniformly. Distill from trajectories weighted by success and information gain, the way sleep preferentially replays salient experience. Consolidating everything wastes the budget and dilutes the signal.
  • Treat retrieval as inert and design around it. Since a store does not revise on access, build explicit update paths: version facts, timestamp them, and expire the stale. Do not assume the system will quietly correct itself the way a memory would.
  • Interleave when you fine-tune. If you update weights on new behaviour, mix in old data to blunt catastrophic interference. The biological system never learns the new in isolation, and neither should yours.
  • Compact with gist, keep the source. Summarization is gist extraction; it loses detail. Keep a pointer to the full episode so a later step can recover specifics the summary dropped.

07Open questions

  • Would a retrieval system that deliberately reconsolidated, rewriting stored memories toward coherence on access, be more useful, or would it inherit the same distortions that make human memory unreliable?
  • What is the right trigger for moving an agent's fast-store experience into the slow store, and can it be learned rather than scheduled by hand?
  • Is there a principled forgetting curve for an external memory, a policy for what to drop that improves retrieval rather than merely saving space?
