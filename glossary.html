glossary

19 key terms · defined once, linked to source

19 terms
Active inference
The idea that action and perception both serve to reduce prediction error: you can change your belief to match the data, or change the data by acting.from Predictive processing and the prediction objective
actor-critic
A reinforcement-learning architecture with an actor that chooses actions and a critic that estimates value; the critic's prediction error trains both.from Reward prediction error, actor-critic, and the alignment of objectives
Anchoring
The tendency for an initial number, even an irrelevant one, to pull subsequent numerical estimates toward it.from Framing, anchoring, and the behavioral economics of the prompt
catastrophic interference
The tendency of a neural network to abruptly lose previously learned information when trained on new data, because the same weights encode both.from Consolidation, replay, and agent memory architecture
complementary learning systems
The theory that the brain uses a fast-learning hippocampus and a slow-learning neocortex together, so new memories can be acquired quickly without overwriting old knowledge.from Consolidation, replay, and agent memory architecture
consolidation
The process by which a labile new memory becomes stable and integrated into long-term neocortical storage, much of it during sleep.from Consolidation, replay, and agent memory architecture
controlled and automatic processing
Schneider and Shiffrin's distinction between effortful, capacity-limited processing and fast, practiced processing that runs without central resources.from Dual-process theory, metacognition, and the reasoning trace
Demand characteristics
Cues in an experiment that convey what response is expected, leading subjects to supply it regardless of their true state.from Framing, anchoring, and the behavioral economics of the prompt
Framing
The finding that logically equivalent descriptions of the same choice, such as survival versus mortality rates, produce systematically different preferences.from Framing, anchoring, and the behavioral economics of the prompt
generative model
An internal model that can produce, or predict, the sensory data it expects, rather than only classifying data after the fact.from Predictive processing and the prediction objective
metacognition
Cognition about cognition: monitoring the state of one's own processing and controlling it, for example knowing that you do not know.from Dual-process theory, metacognition, and the reasoning trace
Position bias
The tendency of a model to use information differently depending on where it sits in the context, often neglecting the middle of a long input.from Framing, anchoring, and the behavioral economics of the prompt
precision
The expected reliability, or inverse variance, of a signal. High-precision errors are trusted and drive learning; low-precision errors are discounted as noise.from Predictive processing and the prediction objective
predictive coding
A theory in which each level of a sensory hierarchy predicts the activity of the level below and transmits only the prediction error upward.from Predictive processing and the prediction objective
reconsolidation
The finding that recalling a memory returns it to an unstable state, requiring restorage, during which it can be updated, strengthened, or impaired.from Consolidation, replay, and agent memory architecture
reward model
A learned model that scores outputs to approximate human preferences, used as the reward signal when fine-tuning a policy with reinforcement learning.from Reward prediction error, actor-critic, and the alignment of objectives
sharp-wave ripples
Brief high-frequency bursts of hippocampal activity, prominent in rest and sleep, during which waking experience is replayed in compressed form.from Consolidation, replay, and agent memory architecture
temporal-difference error
The difference between a predicted value and an updated estimate after one step of experience; the core learning signal in temporal-difference reinforcement learning.from Reward prediction error, actor-critic, and the alignment of objectives
world model
A learned internal simulator of how an environment evolves, which an agent can run forward to plan without acting in the world.from Predictive processing and the prediction objective
